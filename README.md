# kt-client-reports

Витрина разовых клиентских артефактов Команды Роста (аудиты, презентации, отчёты).

- Доступ только по прямой ссылке на конкретную папку — здесь нет общего индекса и ссылок между артефактами.
- Каждый артефакт лежит в своей папке со случайным именем (не связано с именем клиента).
- Страницы помечены `noindex` и закрыты `robots.txt` — но репозиторий технически публичный, это не замена приватности.

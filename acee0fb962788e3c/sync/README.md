# Покупки в Магните

Одна серверная версия списка с архивом, отметками и актуальным Markdown.

- Старая ссылка: https://bggrowthhack-optimizer.github.io/artefacts/acee0fb962788e3c/
- Программа: https://ruslan-shopping-magnit-nov22.arctichotel8.chatgpt.site/app/
- Актуальный MD: https://ruslan-shopping-magnit-nov22.arctichotel8.chatgpt.site/shopping-list.md

Старая страница переносит состояние из `ruslan-magnit-shopping-2026-11-22-v1` через фрагмент адреса. Программа сохраняет перенос до входа и очищает фрагмент. Повторный перенос с тем же идентификатором не применяется. Более новые серверные изменения сохраняются.

## Состояние

Источник истины — D1 `DB`, таблицы `shopping_items`, `shopping_meta`, `shopping_operations`. Каждое действие имеет уникальный ID; повторная отправка не сбрасывает более поздние отметки. Локальная очередь переживает закрытие страницы и отправляется при подключении. Непереданные действия видны в статусе.

MD автоматически пересобирается после сохранения. `/shopping-list.md` формируется из текущего согласованного состояния. В таблице `shopping_markdown` хранится та же версия, разбитая на части по 800 символов. Для чтения из чата: через Sites сначала `read_database_overview`, затем `read_database_table_rows` по таблице `shopping_markdown`; объединить `content` по `id`, проверить одинаковый `revision`. При необходимости сверить `shopping_meta`. Это не прежний снимок файла в Library.

## Доступ

Данные доступны владельцу после входа через ChatGPT. Проверка выполняется на сервере по подтверждённому адресу из `oai-authenticated-user-email` и секрету `SHOP_OWNER_EMAIL`. Служебный доступ требует `SHOP_SERVICE_TOKEN`; секреты настроены в окружении и не входят в исходники. Существующая аудитория Site не меняется; публичная оболочка не даёт доступа к данным. POST дополнительно проверяет Origin.

## Разработка

`node scripts/build.mjs` собирает автономный Worker. `node tests/check.mjs` проверяет миграцию, сохранение, архив, идемпотентность, доступ и Markdown на SQLite в памяти. Схема: `drizzle/0000_shopping.sql`.

# Покупки в Магните

Одна серверная версия списка с архивом, отметками и актуальным Markdown.

- Старая ссылка: https://bggrowthhack-optimizer.github.io/artefacts/acee0fb962788e3c/
- Программа: https://ruslan-shopping-magnit-nov22.arctichotel8.chatgpt.site/app/
- Актуальный MD: https://ruslan-shopping-magnit-nov22.arctichotel8.chatgpt.site/shopping-list.md

Интерфейс работает непосредственно на GitHub Pages, без переадресации. Файлы интерфейса — index.html, style.css, app.js и core.js в папке артефакта. Сервер обслуживает только API и Markdown; разрешён Origin https://bggrowthhack-optimizer.github.io.

Программа переносит состояние из `ruslan-magnit-shopping-2026-11-22-v1` из того же браузера и очищает фрагмент с ключом после его сохранения. Повторный перенос с тем же идентификатором не применяется. Более новые серверные изменения сохраняются.

## Состояние

Источник истины — D1 `DB`, таблицы `shopping_items`, `shopping_meta`, `shopping_operations`. Каждое действие имеет уникальный ID; повторная отправка не сбрасывает более поздние отметки. Локальная очередь переживает закрытие страницы и отправляется при подключении. Непереданные действия видны в статусе.

MD автоматически пересобирается после сохранения. `/shopping-list.md` формируется из текущего согласованного состояния. В таблице `shopping_markdown` хранится та же версия, разбитая на части по 800 символов. Для чтения из чата: через Sites сначала `read_database_overview`, затем `read_database_table_rows` по таблице `shopping_markdown`; объединить `content` по `id`, проверить одинаковый `revision`. При необходимости сверить `shopping_meta`. Это не прежний снимок файла в Library.

## Доступ

Общий семейный список открывается по секретной ссылке без аккаунтов. Ключ берётся из фрагмента адреса и сохраняется в браузере. Программа отправляет его серверу в `X-Shopping-Key`; значение хранится только в секретном окружении `SHOP_LINK_KEY`, в публичных исходниках его нет. Ссылка передаётся семье из меню «Скопировать ссылку для семьи». Без ключа нельзя читать или менять общее состояние. Для служебного доступа сохранён отдельный `SHOP_SERVICE_TOKEN`. POST дополнительно проверяет Origin. Markdown скачивается запросом с ключом, без входа через ChatGPT.

При открытии секретной ссылки приложение читает ключ из фрагмента, а прежний список — из локального сохранения того же домена. Перенос одноразовый; список и архив в базе не пересоздаются. Сам секретный URL в репозиторий не сохраняется.

## Разработка

`node scripts/build.mjs` собирает автономный Worker. `node tests/check.mjs` проверяет миграцию, сохранение, архив, идемпотентность, доступ и Markdown на SQLite в памяти. Схема: `drizzle/0000_shopping.sql`.

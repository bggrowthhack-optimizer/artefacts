Исходные данные и расчёт

Данные для примера. 754 диагностики — исторический ориентир по 13 салонам из аудита. Конверсия 50% и рентабельность 65% — допущения; чек 14 500 ₽ — предварительный ориентир на 10 ноября. Текущая зарплата неизвестна: 70 тыс. ₽ взяты для примера. Замените значения проверенными данными одного периода и одного набора салонов. При изменении охвата отдельно измените общий поток диагностик.

ВП = диагностики × конверсия × средний чек × валовая рентабельность. Поток и рентабельность неизменны, учитываются только заказы после диагностики. Эффект после изменения ФОТ = прирост ВП − (новая зарплата − текущая зарплата) × (1 + доп. начисления / 100). Это эффект до остальных расходов, а не чистая прибыль.

Премии за три KPI начисляются независимо по шкале Марата. Количество салонов с планом влияет на премию; отдельный финансовый эффект планов без их сумм не оценён. Вариант «Текущий» подставляет исходное значение выбранной метрики, в том числе значение ниже первого порога. При 0% начисления на ФОТ не учтены. База зарплаты «на руки / до удержаний» должна быть одинаковой в обоих периодах.

Проект для согласования с Михаилом. Перед запуском проверить 1С, закрепить перечень салонов, состав заказов для среднего чека и правила связи диагностики с заказом. Пилот охватывает семь салонов, ответственность РОПа — 13; исходный пример относится к 13.
